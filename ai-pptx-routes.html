路線 1

傳統 + AI 內嵌

PowerPoint + Copilot

$30/user/月
  • 微軟原生整合
  • 讀取 Designer 模板
  • Word → PPT 一鍵轉換
  • 支援動畫/轉場生成

Claude for PowerPoint

Pro $20/月 起
  • Claude 推理品質
  • 讀取現有母版/品牌
  • Sonnet 4.5 / Opus 4.6 切換
  • 2026/2 研究預覽上線

Google Slides + Gemini

Workspace + AI
  • Google 生態整合
  • 從草圖/語音生版面
  • 多人即時協作
  • 2026 逐步推出中
定位：單份簡報快速產出 + GUI 微調，適合商業簡報、一次性報告

優點

  • 生成後就是正常 PPT，可完全手動微調
  • 編輯彈性最高（GUI 拖拉）
  • 模板/動畫/轉場支援完整
  • 學習門檻最低

缺點

  • AI 品質受模板限制
  • 批量生產困難（一份一份做）
  • 跨份統一性要靠自律
  • 每月費用不低（Copilot $30）
最適合：需要精緻排版 + 手動微調的「單份」商業簡報
不適合：需要批量產出 10+ 份統一風格簡報的場景
路線 2

AI 原生平台

Gamma

Free – $20/月
  • 市場龍頭，70M 用戶，$2.1B 估值
  • 漂亮模板
  • 匯出 PPTX/PDF

Canva AI

Free – $15/月
  • 模板最多，拖拉設計工具
  • 4 份同時生成
  • PPTX 匯出需付費

Beautiful.ai

$12-16/月
  • 智慧排版引擎，自動調整版面
  • 品牌一致性佳
  • 適合團隊

NotebookLM

免費
  • 2026 新功能！源文件導向
  • 零幻覺風險
  • 可匯出 PPTX

Tome 的教訓

2000 萬用戶、$81M 融資，仍在 2025/4 關站。AI 簡報平台的淘汰賽已經開始 — 光靠「AI 生簡報」不夠， 必須有獨特價值（Gamma 靠設計品質、NotebookLM 靠零幻覺）才能存活。

優點

  • 最快出漂亮簡報（幾分鐘內）
  • 非設計師也能產出好看結果
  • 部分平台免費（NotebookLM）
  • 適合快速提案、brainstorm

缺點

  • 排版被平台綁死，自訂空間小
  • 跨份風格不統一
  • 匯出 PPTX 常失真
  • 內容容易骨架化（空洞）
最適合：快速產出一次性簡報
不適合：需要精確控制排版或批量統一
路線 3

AI 對話生成

Claude Artifacts

Free – $200/月
  • 推理品質最強
  • HTML 即時預覽 + 可下載 PPTX
  • 版面多樣（不只 bullet points）
  • 適合深度內容

ChatGPT

Free – $200/月
  • 內容構思能力佳
  • 排版能力弱（千篇一律）
  • Code Interpreter 可生 PPTX
  • 但品質不穩定

Gemini

Free – $20/月
  • 透過 Slides 整合最佳
  • 單獨使用偏弱
  • 適合 Google 生態用戶
  • Advanced $20/月
定位：適合「構思大綱 + 快速草稿」，不適合直接當成品使用
維度Claude ArtifactsChatGPT
版面多樣性高 — 主動變換佈局低 — 標題+Bullet 固定版型
內容深度高 — 推理能力強中 — 容易骨架化
PPTX 品質中高 — 可直接下載低 — Code Interpreter 不穩定
迭代效率高 — 可指定修改特定頁低 — 常需重生整份

優點

  • 內容深度高（AI 推理能力強）
  • 可反覆對話修改
  • 無需學新工具
  • Claude Artifacts 版面多樣

缺點

  • 改一頁常要重生整份
  • 風格不穩定（每次生不同）
  • 批量統一性差
  • 排版控制有限
路線 4

AI Agent

Manus

訂閱制
  • 2025/12 被 Meta 收購
  • 全自動流程：搜集資料 → 建構敘事 → 設計版面
  • 約 7 分鐘完成一份
  • 22M 月訪問量，$100M+ ARR
  • 引用來源可追溯

Felo AI

Free + 付費
  • Claude Code 整合
  • 即時主題設計、靈感主題自動生成版面
  • 上傳自訂 PPT 模板
  • YouTube / PDF → PPT 一鍵轉換
  • felo-skills / felo-cli，可當 Agent 技能使用
定位：全自動研究+生成，適合研究型簡報，但風格不可控、是黑盒操作
自動化程度：最高
給主題 → 搜資料 → 寫內容 → 設計
⟷
控制程度：最低
無法指定版型/配色/字體/頁數

優點

  • 零操作 — 給主題就出整份
  • 自動搜集最新資料
  • 引用來源可追溯（Manus）
  • 適合快速產出 research deck

缺點

  • 完全黑盒 — 無法控制排版細節
  • 風格不可自訂
  • 內容偏「分析型」需要潤飾
  • 批量一致性無法保證
路線 5

IDE 程式生成

Claude Code + pptxgenjs

$20-200/月
  • 像素級精準控制
  • 設計系統程式化
  • 批量生產最強
  • Node.js 生態

Codex (OpenAI)

Pro 附帶
  • 雲端 Agent
  • python-pptx 或 pptxgenjs
  • 自主完成任務
  • 較不互動

Cursor / Antigravity

$15-20/月
  • IDE 原生整合
  • 即時預覽（非 PPT）
  • Background Agents
  • 多 Agent 協作

核心優勢：設計系統程式化

色彩、字體、元件全部用程式碼定義 → 跑 8 份簡報，風格 100% 一致。
這是其他所有方式都做不到的。改一次設計系統 = 所有簡報同步更新。

設計系統色彩定義（寫一次，8 份共用）
const C = {
  navy: "0B3C5D",     // 主色
  teal: "0F9D8A",     // 強調色
  gold: "FFC857",     // 重點色
  darkText: "1A1A1A", // 內文
  mint: "D4F0EB",     // 深色底文字
};

// 元件函數
function titleBar(slide, text) {
  slide.addShape(RECTANGLE,
    { x:0, y:0, w:10, h:0.72,
      fill: { color: C.teal }});
  slide.addText(text, { ... });
}
生成 8 份統一簡報的工作流
# 共用設計系統
pptx-design-system.js  ← 寫一次
  ├── const C = {...}
  ├── titleBar()
  ├── infoCard()
  ├── codeBox()
  └── sectionDivider()

# 8 份簡報各自 import
generate_l1d1.js → require('./design')
generate_l1d2.js → require('./design')
...（共 8 份）

# 一鍵全部重新生成
for f in generate_l*.js; do
  node $f
done

8 份簡報 │ 709 頁投影片 │ 統一設計系統

L1 Day1 (110頁) · L1 Day2 (97頁) · L2 Day1 (85頁) · L2 Day2 (90頁) · L3 Day1 (89頁) · L3 Day2 (74頁) · L3 Day3 (73頁) · L4 PBL (91頁)

同一套 const C 色彩 + helper 函數，跨 8 份檔案風格完全一致

優點

  • 像素級精準排版控制
  • 設計系統跨份 100% 一致
  • 批量生產：改 1 次 = 更新全部
  • 內容深度高（可餵完整資料）

缺點

  • 學習門檻高（需會 JavaScript）
  • 無即時視覺預覽
  • 迭代需跑 code → 開 PPT → 再改
  • 動畫/轉場支援有限
