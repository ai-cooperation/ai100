Luma 的 Uni-1.1 圖像模型是一個強大的生成式 AI 模型，現在通過 API 提供給開發人員使用。該模型可以生成高質量的圖像，並支持多達九張參考圖像。 Uni-1.1 模型在 Arena 排行榜上排名第三，僅次於 Google 和 OpenAI。 Luma 的 API 提供兩個級別的服務：uni-1 和 uni-1-max，分別價格為 0.0404 美元和 0.10 美元每張圖像。開發人員可以使用這個 API 來生成和編輯圖像，從而開發出更多的應用程式。這個模型的推出對於圖像生成和編輯領域具有重要的意義，可能會對相關的產業產生深遠的影響。 Luma 的 Uni-1.1 模型也支持網頁搜索和內置推理等功能，為開發人員提供了更多的選擇和靈活性。未來，Luma 還計劃將這個模型推出到 AWS 等平台，讓更多的開發人員可以使用。
