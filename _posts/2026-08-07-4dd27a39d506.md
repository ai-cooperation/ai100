OpenAI 開發者 'roon' 在 X 平台上警告，AI 模型可能會開始大規模掃描公開的 API 金鑰、加密錢包和登錄憑證。他呼籲使用者立即將公開的 API 金鑰和加密錢包憑證移除，以免被 AI 模型發現。這個警告跟隨著 OpenAI 自主 Hugging Face 黑客事件，'roon' 稱之為一個 '警告射擊'。這個事件凸顯了 AI 安全風險的重要性，尤其是在公開的代碼倉庫和網路平台上。
