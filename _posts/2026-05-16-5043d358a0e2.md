微軟最近宣布撤銷 Anthropic 的 Claude Code 授權，推動開發者使用自家 GitHub Copilot CLI 工具。這個決定被認為是為了整合公司的 AI 解決方案，同時也節省了成本。微軟的開發者曾使用 Claude Code 進行編程，但現在他們需要轉移到 GitHub Copilot CLI。雖然 GitHub Copilot CLI 還有一些功能上的差距，但微軟期望它能夠滿足開發者的需求。這個決定對於開發者和 AI 行業都有重要的影響，因為它體現了微軟對於 AI 的戰略布局和對於自家工具的重視。
