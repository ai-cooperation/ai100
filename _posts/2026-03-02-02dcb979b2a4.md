Anthropic 公司現在提供他們的 $200/月 Claude Max 20x 計劃給開源項目維護者免費使用，適用期為六個月。要符合以下標準：維護者是公開倉庫的主要維護者或核心團隊成員，倉庫在 GitHub 上有 5,000+ 星或 1M+ 月 NPM 下載量，並且在過去三個月內進行過提交、發布或 PR 審查。這個機會對於開源項目維護者來說非常重要，因為它可以幫助他們提高項目的質量和效率。Anthropic 公司的這個舉動也體現了其對開源項目的支持和重視。該公司還表示，即使不完全符合標準的維護者也可以申請，並描述自己的項目和貢獻。
