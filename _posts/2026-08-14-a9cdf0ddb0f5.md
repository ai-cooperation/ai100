Deepseek 近期宣布將其旗艦模型 V4-Pro 移出測試階段，並釋出更新版本。雖然整體排名仍稍落後於 Claude Opus 5 等頂尖模型，但其在 AI 代理 (Agent) 基準測試上的表現已有顯著提升。為了進一步推動生態系發展，Deepseek 同步開源了名為「Deepseek Harness」的軟體，透過模組化的外掛系統，開發者能輕鬆將大型語言模型轉化為具備自主執行能力的 AI 代理。

值得注意的是，伴隨技術升級的是 API 價格的重大調整。新的定價策略導入了「時段計費」機制，在非熱門時段使用較為便宜。然而，快取命中 (Cache hits) 的收費激增至原來的六倍，這意味著若工作流程需要頻繁且重複地讀取相同檔案，將面臨大幅增加的成本。此舉提醒了企業與開發者在導入 Agent 應用時，必須更加謹慎評估與控管 API 預算。
