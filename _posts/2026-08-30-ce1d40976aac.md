EVE Online 自 2003 年上線以來，一直是業界知名的「大規模 Python 應用」經典案例。他們長期使用 Stackless Python 2.7，隨著 Python 2 官方早於多年前停止支援，技術債逐漸累積，這次全面升級至 Python 3 對營運團隊來說是不可避免且充滿挑戰的決定。

為了完成這項史詩級任務，開發團隊將使用自動化腳本處理高達 240 萬行的程式碼，並由人工仔細審查約 2 萬處 Python 2 與 3 的底層行為差異（例如除法運算的結果改變）。此外，他們也在較新的遊戲項目中，成功以開源工具替換掉舊有的架構以適應現代開發需求。

對 AI 與資料科學領域而言，Python 是目前的絕對核心語言。EVE Online 的升級案例凸顯了如何妥善管理大型 Python 專案、應對版本升級帶來的底層變動與測試挑戰，這正是企業級 MLOps 與模型維護過程中同樣會面臨的關鍵課題。
