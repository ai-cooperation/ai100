最近，Simon Willison 進行了一項研究，旨在運行 Python ASGI 應用於瀏覽器中，使用 Pyodide 和 Service Worker。這項技術使得 Python 應用可以在瀏覽器中運行，無需後端伺服器，除了靜態檔案外。這項技術使用 Pyodide 在 WebAssembly 中運行 Python 代碼，然後使用 Service Worker攔截請求，將其轉發到 Python 應用中。這項技術已經被證明可以運行 FastAPI 和 Datasette 等應用。
