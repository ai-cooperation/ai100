Simon Willison 利用 Claude Code 和 Python 創建了一個工具，將他的 iNaturalist 觀察結果分類和展示。他首先建立了一個 Python CLI 工具，然後使用 Git 將結果儲存到 JSON 檔案中。最後，他利用 JavaScript 和 HTML 將觀察結果展示在一個網頁上。這個工具可以自動將觀察結果分類和展示，讓用戶可以更容易地查看和分析自己的觀察結果。這個工具的創建過程展示了 AI 和程式設計的應用，尤其是在自然觀察和資料分析方面。通過這個工具，Simon Willison 可以更有效地管理和分析自己的觀察結果，同時也可以與其他用戶分享自己的發現。
