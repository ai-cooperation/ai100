Cloudflare 的 1.1.1.1 DNS 服務是一個免費的 DNS 查詢工具，現在它提供了一個 CORS 啟用的 JSON API，用於查詢 DNS 記錄。這意味著開發人員可以使用這個 API 在自己的應用程序中查詢 DNS 記錄。Simon Willison 使用這個 API 建立了一個 UI 工具，允許用戶查詢 DNS 記錄。這個工具可以幫助開發人員和用戶更容易地查詢 DNS 記錄，並且可以用於不同的應用程序中。這個工具的出現對於 DNS 查詢和網絡安全具有重要意義。另外，Cloudflare 的 1.1.1.2 和 1.1.1.3 服務分別阻止惡意軟件和成人內容，提供了更安全的 DNS 查詢服務。這些服務的出現可以幫助用戶更安全地瀏覽網絡。
