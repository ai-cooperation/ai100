uv 0.12.0 版本發布，帶來了多項重要變化，尤其是在 uv init 命令產生的默認項目結構上。uv init 是 uv 創建新項目的捷徑，之前的版本 0.11.x 會在項目根目錄下創建 main.py 文件。新版本 uv 0.12.0 將默認項目結構改為 src/ 形式，並配置 uv_build 後端用於構建輪和 .tar.gz 分佈文件。此外，uv-init 被設置為腳本別名，可以通過 uv run uv-init 執行新的 main() 函數。這些變化將對 uv 的使用和項目結構產生重要影響。
