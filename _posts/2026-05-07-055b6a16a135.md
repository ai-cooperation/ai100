Anthropic 的 Code w/ Claude 2026 活動直播，Ami Vora 首先分享了開發者速度的故事，包括 Scott MacVicar 的團隊在 Stripe 和 Felicia Curcuru 的團隊在 Binti 的經驗。接下來，他們介紹了 Mythos 模型在 OpenBSD 源代碼樹中發現 27 年前的漏洞，展示了模型的改進。Anthropic 還宣布了 Claude managed agents 的更新，包括多代理人協調和 Claude Code 程序。這些更新將使開發者更容易使用 Claude 平台，創建更多的 AI 應用程式。這個活動對 AI 學習者來說非常重要，因為它展示了 Anthropic 的最新進展和 Claude 平台的潛力。
