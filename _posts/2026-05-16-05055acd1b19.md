x.AI 公司由 Elon Musk 創立，現在推出其首個終端基於的編碼代理工具 Grok Build。這個工具的推出標誌著 x.AI 進入編碼代理市場，將與 Anthropic 的 Claude Code 和 OpenAI 的 Codex 競爭。Grok Build 目前處於早期測試階段，僅限 SuperGrok Heavy 用戶使用。這個工具提供了多種功能，包括計劃模式、步驟式審核、差異比較和並行子代理等。 existing 配置也可以無縫遷移。這個工具的推出對於開發人員來說是一個重要的消息，因為它可以幫助他們更加高效地編寫代碼和管理項目。
