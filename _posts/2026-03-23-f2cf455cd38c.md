Starlette 是一款基於 ASGI 的 Python 框架，於 2018 年開始開發。它以其簡潔和高效的設計而聞名。Starlette 1.0 的發佈標誌著該框架的一個重要里程碑，具有多個重大的更新和改進。其中包括性能的提升、穩定性的提高和新的功能。 Starlette 的更新對於開發人員來說是一個好消息，因為它可以幫助他們更快速和更容易地建構 Web 應用程式。另外，Starlette 的更新也對於 FastAPI 來說是重要的，因為 FastAPI 是基於 Starlette 的。因此，Starlette 的更新也會間接影響到 FastAPI 的發展。 Starlette 1.0 的發佈是 Python 框架的一個重要事件，對於開發人員和項目來說具有重要的意義。它可以幫助開發人員更快速和更容易地建構 Web 應用程式，同時也會推動 FastAPI 的發展。
