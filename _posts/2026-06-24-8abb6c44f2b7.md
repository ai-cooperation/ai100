最近，Simon Willison 針對在瀏覽器中運行 Python 應用進行了研究，特別是使用 Pyodide 和 WebAssembly 技術。這項技術使得 Python 應用可以在瀏覽器中運行，而無需額外的設置。OPFS（Origin Private File System）是一種允許在瀏覽器中存取和編輯用戶電腦上的文件的技術。通過結合 OPFS 和 Pyodide，Simon Willison 創建了一個測試框架，允許在瀏覽器中運行 Python 應用，並能夠編輯用戶電腦上的 SQLite 文件。這項技術有潛力使得在瀏覽器中運行複雜的應用變得更加容易和方便。這種技術的發展對於 AI 和機器學習的應用也有重要的影響，因為它可以使得更多的用戶能夠在瀏覽器中運行複雜的 AI 模型和應用。
