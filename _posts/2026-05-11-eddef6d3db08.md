GitHub Repo Stats 是一個由 Simon Willison 開發的工具，旨在幫助用戶評估開源項目的質量和活躍度。該工具可以根據 GitHub倉庫 URL 或 foo/bar倉庫 ID 獲取倉庫的統計數據，包括 Commit 數、貢獻者信息、語言分佈、發布詳細信息等。該工具使用 GitHub REST API 獲取數據，並且可以通過認證增加 API 請求限制。這個工具對於開源項目的評估和選擇非常有用，尤其是在移動端界面中，因為 GitHub 的移動端界面中沒有顯示 Commit 數等重要信息。這個工具的開發也體現了 Prompt Engineering 的應用，即根據特定的提示生成特定的工具或功能。
