Anthropic 近期為其 AI 程式碼助手 Claude Code 推出了名為「Mods」的全新外掛系統。這項功能猶如在工具內部運行的中介軟體（Middleware），允許開發者直接透過熟悉的 JavaScript 或 TypeScript 撰寫腳本，深入介入並修改 AI 工具的運行方式與介面呈現。

Mods 系統提供了強大的底層控制力。開發者不僅可以攔截 AI 的工具呼叫（Tool calls）與使用者的提示詞，還能在聊天視窗旁新增自訂的 UI 面板、綁定全新的自訂指令。事實上，Claude Code 官方內建的某些指令（例如 /diff）本身就是利用 Mods 系統建構而成的。這意味著企業或個人開發者可以完全根據自身的工作流程，將 Claude Code 量身打造為高度客製化的專屬 AI 助手。

這項更新凸顯了 AI 開發工具正朝向高度「模組化」的趨勢發展，讓 AI 能更無縫且深度地融入現有的開發環境中。不過官方也特別提醒，Mods 會直接以使用者的系統權限執行，且沒有經過沙盒隔離（Sandbox），因此在安裝第三方外掛時需特別留意資訊安全風險。
