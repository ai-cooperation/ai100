Claude Code 是一個基於 AI 的開發工具，最近它開始使用 Rust 編寫的 Bun。Bun 是一個高性能的 JavaScript 執行引擎，使用 Rust 重寫可以提高執行效率。根據 Jarred Sumner 的說法，Claude Code v2.1.181 和之後的版本都使用了 Rust 版本的 Bun。在 Linux 上，啟動速度提高了 10%。Simon Willison 對自己的 Claude Code 安裝進行了調查，發現了使用 Rust 版本的 Bun 的證據。這個更新可能會對開發者和使用者帶來更好的性能和使用體驗。這個技術的更新對 AI 和軟件開發領域具有重要意義，表明了 Rust 和 Bun 的潛力。
