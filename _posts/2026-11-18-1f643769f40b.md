隨著 AI 代理（AI Agents）自動編寫與執行程式碼的能力越來越強，資訊安全成為了一大隱憂。如果 AI 模型因為理解錯誤，或是遭到惡意的「提示詞注入（Prompt Injection）」攻擊，極有可能在本機電腦上執行具破壞性的系統指令。

為了解決這個潛在威脅，知名開發者 Simon Willison 與 Prime Radiant 實驗室合作，提出了「外部沙盒（External Sandbox）」架構。在這個設計中，AI 代理本身在沙盒外部運作，但當它需要測試或執行程式碼時，會透過 API 將程式送到一個完全隔離的沙盒環境中運行。目前他們已釋出三種實作方案，包含利用 WebAssembly、Apple 容器技術以及微軟的 Quicksand 虛擬化技術。

這項技術對 AI 應用開發非常重要，因為它提供了一套標準化的本機 API 介面。未來開發人員在使用 Claude Code 或 Codex 等自動化 AI 工具時，可以毫無顧慮地讓 AI 自由測試程式碼，大幅提升開發效率，同時確保底層系統絕對安全。
