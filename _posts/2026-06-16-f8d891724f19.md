Anthropic 原本計劃將 Agent SDK 和第三方應用使用從訂閱限制中分離出來，改為使用固定信用額和基於使用的 API 價格。但這個計畫已經引起了開源工具開發者的不滿。Anthropic 放棄這個計畫可能是由於即將到來的與 OpenAI 的價格戰、即將上市和美國政府的壓力等因素。這個決定對開發者和用戶來說是一個好消息，因為它可以避免額外的費用和複雜的計費系統。同時，這也反映了 Anthropic 對用戶需求的關注和對市場競爭的敏感性。對於開發者和企業來說，了解 Anthropic 的計費變更和其背後的原因可以幫助他們更好地選擇和使用合適的 AI 服務和工具。
