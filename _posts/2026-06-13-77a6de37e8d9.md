Moonshot AI 的 Kimi K2.7 Code 是一款開源模型，專為複雜的編程任務和基於代理的工作流程設計。雖然它在標準編程基準測試中落後於 GPT-5.5 和 Claude Opus 4.8，但在實用代理導向測試中表現出色。K2.7 Code 的價格為每百萬輸入令牌 0.95 美元和每百萬輸出令牌 4.00 美元，遠低於競爭對手，成為了一個吸引人的成本有效選擇。這款模型的推出可能會對 AI 編程和開發產業產生重大影響，尤其是在成本和效率方面。開發人員可以利用 Kimi K2.7 Code 完成各種編程任務，同時節省成本和提高效率。這款模型的開源性質也會促進 AI 社區的發展和創新。
