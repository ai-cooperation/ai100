Mario Zechner 是 Pi agent 框架的創建者，他對於當前 AI 開發趨勢的看法很值得重視。他認為我們已經放棄了紀律和控制，陷入了產出大量代碼的瘋狂之中，無視了潛在的風險和後果。這種趨勢是由於 Agent 的出現， Agent 可以快速產出大量代碼，但也可能導致錯誤和混亂。另一方面，人類的干預可以避免這種情況，但當我們完全依賴 Agent 時，就會失去對代碼的控制。這種現象對於 AI 開發來說是非常重要的，因為它關係到我們的未來和安全。
