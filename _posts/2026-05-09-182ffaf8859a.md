近期一篇文章引發了對於使用 HTML 而非 Markdown 作為 Claude Code 輸出格式的討論。該文章指出，使用 HTML 可以讓 Claude Code 輸出更豐富的內容，包括 SVG 圖表、互動小工具和內頁導航等。這使得使用者可以更方便地瀏覽和理解輸出的內容。該文章還提供了許多有趣的例子和提示建議，以展示 HTML 的優點。
