Anthropic 的程式編寫工具 Claude Code 中發現了一個隱藏的監控功能，該功能會秘密標記中國用戶。這個功能是在一個 Reddit帖子中被發現的，帖子中指出 Claude Code 會檢查用戶是否位於中國或使用中國的代理伺服器。這個功能通過系統提示中的隱藏信號來傳輸數據。 Anthropic 宣布將移除此功能，該功能的存在引發了社交媒體上的爭議。這個事件引發了對隱私和數據安全的關注，尤其是在 AI 技術中。這個功能的存在也引發了對 Anthropic 公司的信任問題，該公司需要重新評估其數據處理和使用的政策。這個事件對於一般人來說，是一個關注點，因為它涉及到個人數據的隱私和安全問題，尤其是在使用 AI 技術時。
