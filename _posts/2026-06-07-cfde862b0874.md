Simon Willison 的最新嘗試是使用 MicroPython 和 WebAssembly (WASM) 在沙盒中運行 Python 代碼。這個方法可以提供安全性和 isolated 的環境，讓開發者可以在不影響核心應用程式的情況下嘗試新的功能。 micropython-wasm 包允許開發者在沙盒中運行 Python 代碼，具有安全性和 isolated 的特點。這個方法對於需要運行外部代碼的應用程式非常有用，例如 Datasette Agent 的代碼執行插件。使用 MicroPython 和 WASM 的組合可以提供一個高效和安全的沙盒環境，讓開發者可以專注於開發新功能而不需要擔心安全性問題。
