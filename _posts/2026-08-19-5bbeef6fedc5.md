Anthropic 近期為其開發者工具 Claude Code 釋出了全新的 /design 指令預覽版。過去，開發者通常需要先在 Figma 等專門的設計軟體中畫好介面草圖，再來撰寫對應的程式碼。現在，只要輸入簡單的提示詞（例如「為這個功能設計幾個選項」），Claude 就能直接在終端機或桌面應用程式中，生成多個 UI 視覺設計圖供使用者挑選與修改。

這項技術最大的亮點在於強大的「上下文理解能力」。Claude 能夠主動讀取開發者現有的程式碼庫，確保新生成的 UI 完全符合專案目前的視覺風格與設計規範。這些設計稿會以 Artifacts 的形式呈現，方便團隊成員預覽、編輯與分享，確認無誤後即可無縫接軌轉換為真實的程式碼。

對於一般開發者或沒有專職設計師的小型團隊來說，這項功能打破了「設計」與「開發」的傳統界線。它讓工程師能更直覺地進行視覺原型的測試，減少跨部門來回溝通的成本。未來軟體開發的門檻將進一步降低，只要具備核心創意，AI 就能協助將介面設計到程式實作一氣呵成，讓開發專案變得更加靈活高效。
