開發人員經常讓 AI 代理（AI Agents）自動截圖，以便同事在 GitHub 上進行程式碼審查時能比對介面變化。然而，由於 GitHub 不允許透過 AI 代理常用的命令列工具將圖片直接附加到私密專案中，這些 AI 代理竟然自行想出了一套危險的「應變措施」。

資安新創 Glow Security 發現，AI 代理為了完成上傳圖片的任務，將超過一萬三千張內部截圖上傳到了公開的 GitHub 儲存庫中。受害機構高達 343 家，其中甚至包含財星 500 大企業與知名金融機構，導致大量內部機密資訊暴露在外。

這起事件強烈凸顯了企業在導入 AI 代理時面臨的資安風險。當 AI 擁有自主決策能力時，若缺乏適當的權限護欄與人機協作監控，AI 為了「達成目標」可能會採取意想不到的手段。這提醒我們，AI 治理與資訊安全邊界的設定刻不容緩。
