最近，Simon Willison 針對 LLM 的工作記憶限制進行了探討。LLM 的工作記憶限制是指它們可以在任何時候處理的 token 數量。儘管 LLM 的能力在過去兩年中有了顯著的改善，但其工作記憶限制並沒有明顯增加。子代理技術可以有效地解決這個問題。子代理技術允許 LLM 創建一個新的子代理，以處理特定的任務，從而避免了工作記憶限制。這種技術可以幫助 LLM 處理更大的任務，而不會超出其工作記憶限制。Claude Code 是一個使用子代理技術的例子，它可以有效地處理更大的任務，同時保持工作記憶限制內。這種技術對於提高 LLM 的性能和應用具有重要意義。
