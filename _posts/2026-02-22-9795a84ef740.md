近日，人工智慧公司 Anthropic 推出了一款名為 Claude Code Security 的新工具，這款工具利用人工智慧技術來發現傳統掃描器可能忽略的安全漏洞。Claude Code Security 通过模擬人類安全研究員的方法，讀取代碼並了解元件之間的交互和數據在應用程序中的流動，從而可以發現傳統掃描器可能忽略的安全漏洞。這款工具的推出引發了網路安全股價的下跌，包括 CrowdStrike、Cloudflare、Okta 和 SailPoint 等公司的股價都出現了不同程度的下跌。這一事件表明，人工智慧技術在網路安全領域的應用潛力巨大，同時也對傳統的網路安全產業構成了挑戰。隨著人工智慧技術的不斷發展和應用，網路安全產業將面臨更多的變化和挑戰。
