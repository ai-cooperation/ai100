Python Vulnerability Lookup 工具可以幫助開發者檢查 Python 專案中的安全漏洞。這個工具可以通過貼入 pyproject.toml 或 requirements.txt 文件，或者從 GitHub 存儲庫中加載依賴項來查找已知的安全漏洞。工具會查詢 OSV.dev 開源漏洞數據庫，顯示詳細的漏洞信息，包括嚴重級別、受影響的版本範圍和全面的披露報告。這個工具可以幫助開發者及時發現和修復安全漏洞，提高 Python 專案的安全性。該工具的開發是基於 OSV.dev 的開放 CORS JSON API，使用 Claude Code 建立的 HTML 工具。
