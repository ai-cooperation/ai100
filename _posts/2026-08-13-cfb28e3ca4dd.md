微軟最近推出了新的代碼模型 MAI Code 1.1 Flash，該模型被設計用於 GitHub Copilot。然而，在benchmark測試中，MAI Code 1.1 Flash 被 Deepseek V4 Flash 超越，後者在價格和性能上都更優秀。微軟宣稱 MAI Code 1.1 Flash 的性能提高了 25%，成本也降低了四分之一。然而，開發人員更偏愛使用 OpenWeight 替代方案。這個結果表明，微軟的 MAI 模型仍然需要改進，以便在市場上競爭。這個事件對於 AI 學習者來說很重要，因為它反映了目前 AI 代碼模型的發展趨勢和挑戰。另外，了解不同代碼模型的優缺點對於開發人員來說也很重要，以便他們可以選擇最適合的工具來完成自己的工作。
