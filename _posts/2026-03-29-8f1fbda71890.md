Simon Willison 近期購買了一台新的 MacBook Pro，並體驗到使用 LLM 開發 macOS 應用程式的樂趣。他使用 Claude Opus 4.6 和 GPT-5.4 開發了兩個應用程式：Bandwidther 和 Gpuer，分別用於監測網路頻寬和 GPU 活動。這些應用程式都是使用 SwiftUI 開發的，並且可以直接從文字檔案中運行，不需要開啟 Xcode。這個體驗讓 Simon Willison 感到 vibe coding 的樂趣和效率。這個技術可以讓開發者快速地建立和測試新的應用程式，對於 macOS 應用程式的開發具有重要意義。對於一般人來說，這個技術可以讓他們更容易地使用和開發 macOS 應用程式，提高工作效率和生活品質。
