微軟最近宣布推出兩個新的人工智慧模型：MAI-Thinking-1 和 MAI-Code-1-Flash。MAI-Thinking-1 是一個 1T 參數的推理模型，具有 35B 活躍參數，目前僅供選定的早期合作夥伴使用。MAI-Code-1-Flash 是一個 137B 參數的編碼模型，具有 5B 活躍參數，旨在為 GitHub Copilot 和 VS Code 提供高性能和低成本的編碼體驗。這兩個模型都使用了企業級別的清潔和商業授權的數據進行訓練，顯示了微軟在開發人工智慧模型方面的努力。這些模型的推出對於開發者和企業來說具有重要意義，因為它們可以提供更好的推理和編碼能力，從而提高生產力和效率。另外，這也體現了微軟在人工智慧領域的投入和創新，對於未來的人工智慧發展具有重要影響。
