GitHub 儲存庫大小工具是由 Simon Willison 發佈的一個工具，讓用戶可以查看 GitHub 儲存庫的大小。這個工具使用 GitHub 的 CORS-friendly API 來取得儲存庫大小的資訊。用戶可以將儲存庫的 URL 複製到工具中，就可以查看儲存庫的大小。這個工具對於開發者來說非常有用，因為它可以幫助他們了解儲存庫的大小和管理儲存庫的空間。另外，這個工具也可以用來比較不同儲存庫的大小，從而幫助用戶選擇合適的儲存庫。
