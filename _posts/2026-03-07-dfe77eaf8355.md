Anthropic 推出全新的「/loop」指令，讓 Claude Code 桌面版具備了本地定時執行任務的能力。使用者可以透過標準的 cron 表達式或自然語言指令（例如「下午三點提醒我推送分支」）來安排任務。這項功能支援在背景運作，並能自動清理超過三天的過期任務，單一會話最多可同時運行 50 個任務，讓開發環境轉向自動化運作。

這項更新的重大意義在於將 AI 從「被動回應」轉變為「主動執行」。例如，AI 可以每隔幾小時自動掃描系統錯誤日誌，並在發現可修復的 Bug 時直接建立 Pull Request 供開發者審核。對於開發者而言，這能大幅減少處理繁瑣例行公事的時間，讓 AI 真正成為具備自主行動能力的背景工作員，標誌著代理型 AI（Agentic AI）在實際工作流程中的深度整合。
