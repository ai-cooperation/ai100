Anthropic 公司最近更新了其 Claude Code 平台，新增了多個桌面功能，以自動化開發工作流程。這些功能包括自動啟動開發伺服器、顯示運行中的網頁應用程序、自動修復錯誤和代碼審查等。Claude Code 現在可以自動修復 CI 錯誤，甚至可以合並 pull request。這意味著開發者可以將更多的時間投入到新任務中，而 Claude Code 則可以在後台自動完成開發工作流程。這項更新將大大提高開發者的工作效率和生產力。
