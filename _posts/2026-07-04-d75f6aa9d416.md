Claude Code 是一種人工智慧工具，由 Anthropic 開發。然而，該公司的服務條款明確禁止向中國控制的公司銷售。但是，像 Ant Financial 和 ByteDance 這樣的中國公司通過雲服務、海外子公司或 VPN 等方式規避了這些限制。另一方面，阿里巴巴也禁止其員工使用 Claude Code，並要求刪除所有 Claude 模型。這些限制和規避行為反映了人工智慧工具在全球市場上的複雜性和敏感性。 Claude Code 的封鎖和規避問題不僅關乎商業利益，也涉及到國家安全和資料隱私等問題。因此，了解這些問題對於人工智慧的發展和應用具有重要意義。
