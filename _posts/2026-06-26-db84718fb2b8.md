Simon Willison 啟發於 Mozilla 的新 MDN MCP 服務，決定將 Mozilla 的瀏覽器相容性資料庫轉換為 SQLite。這個新 GitHub 存儲庫包含了一個 Claude Code 生成的腳本，使用 sqlite-utils 將資料庫建構起來。結果是一個約 66MB 的 SQLite 數據庫，經由 GitHub CDN 提供下載，並具有開啟的 CORS 標頭，允許使用 Datasette Lite 進行探索。這個項目的目的是提供一個方便存取和查詢瀏覽器相容性資料的方式，對於前端開發者和瀏覽器製造商都具有參考價值。
