Claude Code 團隊的 Cat Wu 和 Thariq Shihipar 在 AI Engineer World's Fair 上與 Simon Willison 進行了一場火邊聊天，討論了 Claude Code、Claude Tag、Fable 等工具的開發和應用。他們分享了 Anthropic 如何使用這些工具來提高開發效率和安全性。例如，Claude Tag 已經成為 Claude Code 團隊的主要協作工具，佔了 65% 的產品工程 PRs。另外，Critical 的變更仍然需要人工審查，但團隊正在增加使用自動代碼審查來提高開發速度。這些工具和方法的發展對於提高 AI 開發的效率和安全性具有重要意義，值得關注和學習。這場聊天的內容已經在 YouTube 上發布，供大家參考學習
