近期，Simon Willison 進行了一項關於 JavaScript 沙盒的研究，旨在比較 Node.js 中的隔離選項。這項研究比較了 worker_threads、isolated-vm、vm2 和 quickjs-emscripten 等選項，探討了如何在 Node.js 中安全地運行不可信任的 JavaScript 代碼。這項研究對於開發人員和企業來說具有重要意義，因為它可以幫助他們選擇合適的隔離方案，保護他們的應用程序免受潛在的安全威脅。另外，該研究還探討了 Deno Workers 和 ShadowRealm 等其他選項，提供了更全面性的比較和分析
