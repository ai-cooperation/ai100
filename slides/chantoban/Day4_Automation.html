GAS 常見錯誤 Top 5

#錯誤原因 & 解法
1 Authorization required 沒授權 → 重新執行，按「審查權限」
2 Cannot read property of null 試算表名稱或欄位對不上 → 檢查資料範圍
3 Service invocations exceeded 超過每日免費額度 → 明天再跑或分批
4 Exceeded max execution time 腳本跑太久（>6分鐘）→ 縮小資料範圍
5 Invalid email address Email 格式錯 → 檢查試算表資料

function sendWeeklyReport() { var sheet = SpreadsheetApp.getActiveSheet(); var data = sheet.getDataRange().getValues(); var today = new Date(); var weekAgo = new Date(today.getTime() - 7*24*60*60*1000); var report = '本週成交清單\n' + '='.repeat(30) + '\n'; var totalAmount = 0; var count = 0; for (var i = 1; i < data.length; i++) { var date = new Date(data[i][0]); // A: 日期 var client = data[i][1]; // B: 客戶 var amount = data[i][2]; // C: 金額 if (date >= weekAgo && date <= today) { report += client + ' — $' + amount.toLocaleString() + '\n'; totalAmount += amount; count++; } } report += '='.repeat(30) + '\n' + '本週成交 ' + count + ' 筆，' + '合計 $' + totalAmount.toLocaleString(); GmailApp.sendEmail('boss@company.com', '【週報】本週成交摘要', report); }
