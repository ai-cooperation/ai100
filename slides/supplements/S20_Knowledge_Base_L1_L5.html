L3 工具 — 四層組合技

Layer 1

📋 CLAUDE.md — AI 的工作規則

定義專案背景、命名規範、行為約束。AI 的「員工手冊」，所有動作的基礎。

Layer 2

🛠️ Skills — AI 的技能擴展

可重複呼叫的專業能力：生成簡報、同步知識庫、品質檢查。一次定義，永久複用。

Layer 3

🔌 MCP — AI 的系統連接

Model Context Protocol：讓 AI 串接外部服務（Notion API、GitHub、資料庫）。

外部

🐙 GitHub Actions + 🔗 Notion API — 自動化基礎設施

git push 觸發 CI/CD、API 自動同步 — 這些是 MCP 連接的「對象」。

四層從內到外：規則 → 技能 → 連接 → 外部服務。Claude Code 是執行引擎，在這四層之上運作。

流程再設計 — AS-IS → TO-BE

AS-IS 原本流程

1. 收到新簡報需求
2. 從零開始找資料
3. 一篇篇讀、手動摘錄
4. 排版、設計、修改
5. 重複以上（每次都重來）

⏱ 每份簡報 8-16 小時

→
TO-BE 改造後

1. 收到新簡報需求
2. 指定受眾 + 目的 + 主題
3. AI 從知識庫自動重組
4. 審核、微調、交付
5. 新知識回存知識庫

⏱ 每份簡報 1-3 小時

知識庫不再只是「倉庫」— 它是你的「彈藥庫」。每次新任務，都是重新組裝。

知識是可重複利用的資產 — 建立「收→存→用→回存」循環
