動手做 — 迭代

Vibe Coding 的威力：迭代速度

跟 Claude 說就好，一句話改一版

「把配色改成___色系」
「加一個___區塊」
「手機版要用漢堡選單」
核心觀念

Vibe Coding 的威力不在第一版完美，在於迭代速度。
傳統改一版要半天，現在一句話就好。

迭代範例：三輪對話

v1
「做一個個人履歷網站」

→ AI 產出基本版，有名字、經歷、技能

v2
「加一個作品集區塊，用卡片排列，每張卡片有圖片、標題、描述」

→ 出現漂亮的 gallery

v3
「整體配色改成深藍+金色，加上滑入動畫效果」

→ 質感提升，像專業設計師做的

三句話 = 三分鐘 = 三次升級
