安裝 gws

# 前置需求：gcloud CLI
brew install --cask google-cloud-sdk
gcloud auth login

# 安裝 gws
npm install -g @googleworkspace/cli

# 認證設定
gcloud config set project <your-project-id>
gws auth setup

Part 2

使用範例

Drive・Gmail・Sheets・Calendar

Drive 操作

# 列出 Drive 檔案
gws drive files list

# 搜尋檔案
gws drive files list --query "name contains '報告'"

# 上傳檔案
gws drive files upload --file ./report.pdf

# 刪除檔案（移到垃圾桶）
gws drive files trash <fileId>

Gmail & Sheets 操作

Gmail

# 搜尋郵件
gws gmail messages list \
  --query "from:boss@co.com"

# 寄送郵件
gws gmail messages send \
  --to "user@ex.com" \
  --subject "Hello" \
  --body "Hi there"

Sheets

# 讀取試算表
gws sheets spreadsheets \
  get <spreadsheetId>

# 讀取特定範圍
gws sheets values get \
  <spreadsheetId> \
  --range "Sheet1!A1:D10"

Calendar 操作

# 列出行事曆事件
gws calendar events list --calendar primary

# 建立事件
gws calendar events create \
  --calendar primary \
  --summary "開會" \
  --start "2026-03-06T10:00:00"

作為 MCP Server

讓 Claude Code 直接操作 Google Workspace

// ~/.claude/settings.json
{
  "mcpServers": {
    "google-workspace": {
      "command": "gws",
      "args": ["mcp", "start"]
    }
  }
}
設定後 Claude Code 可以

搜尋 Drive 檔案、讀取 Sheets 資料、管理 Calendar 事件、寄送 Gmail — 全部用自然語言指揮

clasp vs gws

claspgws
用途開發 Google Apps Script操作 Google Workspace 服務
範圍只管 GAS 專案Drive・Gmail・Calendar・Sheets...
操作push / pull / deploy 程式碼CRUD 操作所有 Google 資源
適合寫 GAS 自動化腳本從 CLI 直接操作 Google
