clasp
把 GAS 搬回 VS Code

Google Apps Script 本地開發工具

按 → 或空白鍵開始

網頁編輯器的痛點 → clasp 的解法

網頁編輯器痛點clasp 解決方案
沒有 Git 版控本地開發，完整 Git 支援
編輯器功能陽春VS Code + 自動補全 + Copilot
無法多人協作Git branch + PR 工作流
只支援 JavaScript支援 TypeScript
部署靠手動clasp deploy 一鍵部署

安裝 clasp

npm install -g @google/clasp
clasp login   # 瀏覽器授權 Google 帳號

就這兩行，clasp 就裝好了。

核心指令

指令用途
clasp create建立新 GAS 專案
clasp clone <id>拉取現有專案
clasp pull從雲端拉回程式碼
clasp push推送到雲端
clasp deploy部署新版本
clasp open瀏覽器開啟編輯器

實際工作流

1
clasp clone <scriptId>

拉取現有 GAS 專案到本地

2
VS Code 編輯程式碼

本地開發，有 Copilot 幫忙

3
clasp push

推送到 Google 雲端

4
Google Sheets 測試

驗證功能正確

5
clasp deploy

部署正式版

專案結構

my-gas-project/
├── .clasp.json       # 專案 ID 設定（不要刪）
├── appsscript.json  # GAS 設定（權限、觸發器）
├── Code.js           # 主程式
└── Utils.js          # 工具函式

注意事項

!
clasp push 會覆蓋雲端

多人使用要先 clasp pull，避免覆蓋別人的修改

!
.clasp.json 加入 .gitignore

包含專案 ID，避免多人衝突

!
GAS 執行有時間限制

6 分鐘 / 次，大型作業要分批處理
