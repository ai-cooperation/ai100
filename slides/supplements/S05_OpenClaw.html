什麼是 Docker？

比喻

Docker = 外送餐盒

廚師（開發者）把菜做好，放進餐盒（Docker image）
你只要打開加熱（docker run），不用自己買食材、洗菜、開火

不用 Docker：裝 Python → 裝套件 → 設定環境變數 → 調設定檔 → 祈禱

用 Docker：一行指令，全部搞定
