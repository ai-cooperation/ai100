Part 3

安裝與結構

3 分鐘安裝，立即提升

3 分鐘安裝

# 下載
git clone https://github.com/affaan-m/everything-claude-code.git
cd everything-claude-code

# 安裝（選擇你用的語言）
./install.sh python            # 只裝 Python
./install.sh typescript        # 只裝 TypeScript
./install.sh python typescript # 兩個都裝
安裝位置

Rules 放在 ~/.claude/rules/，Claude Code 和 Claude for VS Code 都會自動載入。

安裝了什麼？

~/.claude/rules/
├── common/                  # 通用規則（所有語言）
│   ├── agents.md            # Agent 協作
│   ├── coding-style.md      # 程式碼風格
│   ├── development-workflow.md
│   ├── git-workflow.md
│   ├── security.md          # 安全規範
│   └── testing.md           # 測試規範
├── python/                 # Python 專屬
└── typescript/             # TypeScript 專屬
