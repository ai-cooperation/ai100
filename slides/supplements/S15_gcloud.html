Part 2

認證相關指令

gcloud 的核心能力

認證指令

gcloud auth login                        # 基本登入
gcloud auth login --enable-gdrive-access # + Drive 存取
gcloud auth print-access-token           # 取得 token
gcloud auth list                       # 列出帳號
gcloud auth revoke                     # 撤銷認證
重要

登入時選 --enable-gdrive-access 才能存取 Drive — 預設沒有。

專案 & API 管理

# 專案管理
gcloud projects list               # 列出所有專案
gcloud config set project <id>    # 切換專案
gcloud config get-value project   # 查看目前

# API 管理
gcloud services list --enabled         # 已啟用的 API
gcloud services enable drive.googleapis.com
gcloud services enable sheets.googleapis.com

進階：直接呼叫 Google API

# 取得 token
TOKEN=$(gcloud auth print-access-token)

# 列出 Drive 檔案
curl -H "Authorization: Bearer $TOKEN" \
  "https://www.googleapis.com/drive/v3/files?pageSize=10"

# 刪除檔案（移到垃圾桶）
curl -X PATCH -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"trashed": true}' \
  "https://www.googleapis.com/drive/v3/files/<fileId>"

搭配 AI 工具的實用場景

gcloud vs gws vs clasp

工具用途範圍
gcloudGCP 資源管理 + 認證基礎整個 Google Cloud
gwsGoogle Workspace 操作Drive・Gmail・Calendar・Sheets
claspGAS 開發只管 Apps Script 專案

注意事項

!
Drive 存取需額外授權

登入時加 --enable-gdrive-access，預設沒有 Drive 權限

!
Token 有效期 1 小時

access token 過期後需重新取得

!
ADC 不支援部分 Workspace API

Application Default Credentials 不適用某些 API，要用 user credentials
