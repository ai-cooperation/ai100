🔒 Permission 設定參考

安全模式 每個動作都要確認

適合初學者，AI 做任何事都會先問你

{ "permissions": { "allow": [], "deny": ["Bash(*)", "Write(*)", "Edit(*)"] } }

半自動 常用操作自動，危險操作要確認

適合有經驗的使用者，讀取和搜尋自動允許

{ "permissions": { "allow": [ "Bash(git *)", "Bash(ls *)", "Bash(cat *)", "Read(*)", "Glob(*)", "Grep(*)" ], "deny": ["Bash(rm -rf *)"] } }

Bypass 模式 全自動（進階用戶）

AI 自動執行所有操作，只有危險指令會被攔截

{ "permissions": { "allow": ["Bash(*)", "Write(*)", "Edit(*)"], "deny": ["Bash(rm -rf /*)"] } }
