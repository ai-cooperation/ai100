⌨️ VS Code 常用快捷鍵

快捷鍵功能說明
Ctrl+Shift+PCommand Palette所有功能的入口，最重要的快捷鍵
Ctrl+`Toggle Terminal開關終端機面板
Ctrl+BToggle Sidebar開關左邊檔案列表
Ctrl+DSelect Next選取下一個相同文字（批量改名神器）
Alt+↑/↓Move Line上下移動整行程式碼
Ctrl+/Toggle Comment註解/取消註解該行
Ctrl+Shift+KDelete Line刪除整行
Ctrl+PQuick Open快速開啟檔案（輸入檔名）

🤖 Claude 專用操作

選取程式碼 → 右鍵 → Ask Claude
選取任何一段程式碼，右鍵選單中選「Ask Claude」，就能請 AI 解釋、重構、找 bug。
也可以用 Ctrl+Shift+P → 輸入「Claude」看到所有 Claude 指令。

📁 網頁專案架構範本

標準網頁專案結構

開新專案時，建議按照這個結構整理檔案：

project/ ├── index.html ← 首頁（瀏覽器打開的第一個檔案） ├── css/ │ └── style.css ← 外觀樣式（顏色、排版、字型） ├── js/ │ └── main.js ← 互動行為（按鈕、動畫、表單） ├── images/ ← 圖片素材 │ ├── logo.png │ └── hero.jpg ├── CLAUDE.md ← AI 規則（告訴 AI 怎麼幫你寫 code） └── README.md ← 專案說明（這個專案是什麼）

💡 為什麼要分資料夾？

不分類：所有檔案混在一起，10 個檔案以上就會找不到東西。
分類後：CSS 改外觀去 css/，加功能去 js/，換圖片去 images/。
AI 也更容易理解你的專案結構，給出更好的建議。
