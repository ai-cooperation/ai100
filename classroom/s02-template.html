📦 GitHub Pages 部署步驟

免費把你的網頁上線到全世界

不需要伺服器、不需要付錢，8 個步驟搞定

  1. 前往 github.com，註冊帳號（或登入）
  2. 右上角 + → New repository
  3. Repository name 填：你的帳號名.github.io
  4. 選 Public → 點 Create repository
  5. 點 "uploading an existing file" → 拖入你的 index.html
  6. 點 Commit changes
  7. 等 1 分鐘 → 打開 你的帳號.github.io
  8. 如果要改內容：直接在 GitHub 上點檔案 → 編輯 → Commit
