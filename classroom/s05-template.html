🤖 BotFather 建立 Bot 步驟

  1. 打開 Telegram → 搜尋 @BotFather
  2. 發送 /newbot
  3. 輸入 Bot 名稱（如「我的AI助手」）
  4. 輸入 Bot username（如 myai_helper_bot，必須以 _bot 結尾）
  5. 複製 token（格式：1234567:AAH...）
  6. 不要分享 token！ 拿到 token 的人可以控制你的 Bot

💻 安裝指令

Docker 推薦方式（一行搞定）

電腦已有 Docker 的話，最快的安裝方式：

docker run -d --name openclaw -v openclaw_data:/data openclaw/openclaw

npm Node.js 安裝

已有 Node.js 環境的話，用 npm 安裝：

npm install -g openclaw

Zeabur 雲端一鍵部署（不用裝任何東西）

完全不碰命令列！前往 Zeabur 點一下就部署好了。

前往 zeabur.com/templates/VTZ4FX 一鍵部署
前往 Zeabur 部署 →
