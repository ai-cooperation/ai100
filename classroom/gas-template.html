⭐⭐⭐ 問卷產生器（GAS 建立網頁表單）

GAS doGet() 部署成網頁 → 別人填寫 → 資料自動進 Sheet

請幫我寫一段 Google Apps Script，包含兩個部分： 【Part 1: 網頁表單 — doGet()】 用 HtmlService 回傳一個好看的 HTML 問卷表單。 問卷標題：「課程滿意度調查」 包含以下欄位： 1. 姓名（文字輸入） 2. 整體滿意度（單選：非常滿意/滿意/普通/不滿意） 3. 最喜歡的部分（文字輸入） 4. 最需要改進的地方（文字輸入） 5. 推薦意願 1-10 分（數字滑桿） 表單要手機友善（RWD），配色乾淨專業。 送出後顯示「感謝填寫！」 【Part 2: 資料接收 — doPost()】 表單送出後，將資料寫入 Sheet： A 欄：時間戳記 B 欄：姓名 C 欄：滿意度 D 欄：最喜歡的部分 E 欄：需要改進 F 欄：推薦分數 不需要 API Key（這個不用 AI，純表單）。 程式碼要有中文註解。

⭐⭐⭐⭐ 統計報表（Sheet → Google Docs）

匯整所有問卷 → AI 產生分析報告 → 自動建立 Docs

請幫我寫一段 Google Apps Script。 功能：讀取 Sheet 所有問卷回覆，用 AI 產生統計報告，寫入 Google Docs。 步驟： 1. 讀取 Sheet 的 A2 到最後一列（跳過標題） 2. 統計基本數據：總填寫人數、各滿意度比例、平均推薦分數 3. 把所有「最喜歡」和「需要改進」的文字打包 4. 呼叫 Groq AI，Prompt： 「以下是課程問卷的所有回覆。請分析並產生： 1. 整體滿意度總結（2-3 句） 2. 前三大正面意見 3. 前三大需要改進的地方 4. 給講師的具體建議（3 點）」 5. 用 DocumentApp.create() 建立新的 Google Docs 6. 寫入標題、日期、統計數字、AI 分析內容 7. 在 Sheet 的某格記錄 Docs 連結 API：Groq 模型：llama-3.3-70b-versatile API Key 用 PropertiesService。 程式碼要有中文註解。

🎨 補充案例：GAS × AI 生圖

🆕 圖片 用 GAS 呼叫 AI 生成圖片

前面五個案例都是「文字 AI」— 這個補充案例讓你用 GAS 串「圖片 AI」！
A1 輸入描述 → 執行 → 圖片自動插入 Sheet + 存到 Drive。

使用 GemGate — 免費 AI 圖片 API（不需信用卡）

Step 1 註冊 API Key（10 秒）

打開 GemGate → 輸入你的代號 → 立刻拿到 gg-xxx API Key

🔑 前往 GemGate 註冊 →

Step 2 Prompt（貼到 ChatGPT 讓它寫 code）

跟前面一樣，讓 AI 幫你寫 GAS 程式碼：

請幫我寫一段 Google Apps Script。 功能：A1 輸入圖片描述，執行後圖片插入 Sheet 的 C1，Drive 連結寫到 B1。 API 端點：http://43.159.131.124:8760/v1/images/generations 呼叫方式：POST，Header 帶 Authorization: Bearer API_KEY Body：{"model":"gemini-image","prompt":"A1的內容","n":1,"size":"1024x1024"} 回傳格式：{"data":[{"b64_json":"base64圖片資料"}]} 用 Utilities.base64Decode + Utilities.newBlob 把 base64 變圖片。 用 sheet.insertImage(blob, 3, 1) 插入 Sheet。 用 DriveApp 存一份到 Drive。 API Key 用 PropertiesService，不寫死。 503 錯誤自動重試最多 3 次（間隔 3 秒）。 程式碼要有中文註解。

Step 3 或者直接用這段完整程式碼

不想問 ChatGPT？直接複製貼到 Apps Script 就能跑：

var GEMGATE_URL = "http://43.159.131.124:8760"; function generateImage() { var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet(); var prompt = sheet.getRange("A1").getValue(); var apiKey = PropertiesService.getScriptProperties().getProperty("GEMGATE_API_KEY"); if (!prompt) { SpreadsheetApp.getUi().alert("請在 A1 輸入圖片描述！"); return; } if (!apiKey) { SpreadsheetApp.getUi().alert("請先執行「設定 API Key」"); return; } sheet.getRange("B1").setValue("⏳ 生成中（約 30-60 秒）..."); SpreadsheetApp.flush(); var payload = {model:"gemini-image", prompt:prompt, n:1, size:"1024x1024"}; var options = { method: "post", contentType: "application/json", headers: {"Authorization": "Bearer " + apiKey}, payload: JSON.stringify(payload), muteHttpExceptions: true }; // 最多重試 3 次（503 = 暫時失敗） var response, code; for (var i = 1; i <= 3; i++) { if (i > 1) { Utilities.sleep(3000); } response = UrlFetchApp.fetch(GEMGATE_URL + "/v1/images/generations", options); code = response.getResponseCode(); if (code === 200 || code !== 503) break; } if (code !== 200) { sheet.getRange("B1").setValue("❌ 錯誤 " + code); return; } var json = JSON.parse(response.getContentText()); var b64 = json.data[0].b64_json; var blob = Utilities.newBlob(Utilities.base64Decode(b64), "image/png", "ai_image.png"); // 存到 Drive var folders = DriveApp.getFoldersByName("GAS_AI_Images"); var folder = folders.hasNext() ? folders.next() : DriveApp.createFolder("GAS_AI_Images"); var file = folder.createFile(blob); sheet.getRange("B1").setValue("✅ 完成！"); sheet.getRange("B2").setFormula('=HYPERLINK("' + file.getUrl() + '","🖼️ 查看圖片")'); sheet.insertImage(blob, 3, 1); } function setup() { var ui = SpreadsheetApp.getUi(); var result = ui.prompt("設定 API Key", "輸入你的 GemGate Key（gg-xxx）：", ui.ButtonSet.OK_CANCEL); if (result.getSelectedButton() === ui.Button.OK) { PropertiesService.getScriptProperties().setProperty("GEMGATE_API_KEY", result.getResponseText().trim()); ui.alert("✅ Key 已儲存！"); } } function onOpen() { SpreadsheetApp.getUi().createMenu("🎨 AI 生圖") .addItem("生成圖片", "generateImage") .addItem("設定 API Key", "setup") .addToUi(); }

💡 跟前面案例的差異

Groq 回傳文字 → 你用 JSON.parse 拿文字寫入格子
GemGate 回傳圖片（base64） → 你用 Utilities.newBlob 把 base64 變成圖片檔
其餘 UrlFetchApp、headers、JSON.stringify 完全一樣！

🎯 會了文字 API + 圖片 API，GAS 就能做出「有圖有文」的完整自動化。
